# VanLevel Support

VanLevel helps level a caravan using either the iPhone’s motion sensors or an optional dedicated VanLevel Bluetooth sensor. This repository is the public source for the VanLevel support and privacy pages.

## Using this iPhone

1. On first launch, choose **This iPhone**, enter the actual caravan measurements and confirm them.
2. Place the iPhone flat and screen up in portrait.
3. Point the top of the iPhone toward the front of the caravan.
4. Place it on a verified level surface and select **Set Current Position as Level**.
5. Keep the phone still while VanLevel settles, then follow the displayed guidance.

Use the same phone orientation each time. Remove cases that rock on the camera bump, and avoid soft or curved surfaces.

## Using the VanLevel sensor

Power on the sensor, select **VanLevel sensor** during first-run setup and keep the phone nearby. VanLevel discovers and reconnects to the sensor automatically. Open **Settings → Caravan & sensor setup**, enter the actual measurements, select the physical mounting orientation and confirm the setup before saving it to the sensor. The sensor must be mounted rigidly and calibrated on a verified level surface.

Left and right always mean the direction seen while standing inside the caravan and facing the front / jockey-wheel end. Each mounting preset specifies the screen direction and USB-C port direction to remove ambiguity. Changing an installed sensor’s orientation clears its saved level; calibrate it again afterwards.

## Troubleshooting

- If phone guidance remains paused, place the phone down and stop touching the caravan briefly.
- If calibration seems incorrect, clear the saved level and calibrate again on a verified level surface.
- If Bluetooth does not connect, confirm Bluetooth access is allowed, power-cycle the sensor and select Try Again.
- Diagnostics shows live readings, stability, connection state and update rate.

For additional help or to report a problem, [open a support issue](https://github.com/RyanANewstead/VanLevel-Support/issues).
