# VanLevel Support

VanLevel helps level a caravan using either the iPhone’s motion sensors or an optional dedicated VanLevel Bluetooth sensor.

## Using this iPhone

1. Open Settings and choose **This iPhone** as the measurement source.
2. Place the iPhone flat and screen up in portrait.
3. Point the top of the iPhone toward the front of the caravan.
4. Place it on a verified level surface and select **Set Current Position as Level**.
5. Keep the phone still while VanLevel settles, then follow the displayed guidance.

Use the same phone orientation each time. Remove cases that rock on the camera bump, and avoid soft or curved surfaces.

## Using the VanLevel sensor

Power on the sensor, select **VanLevel sensor** in Settings and keep the phone nearby. VanLevel discovers and reconnects to the sensor automatically. The sensor must be mounted rigidly in its documented orientation and calibrated on a verified level surface.

## Troubleshooting

- If phone guidance remains paused, place the phone down and stop touching the caravan briefly.
- If calibration seems incorrect, clear the saved level and calibrate again on a verified level surface.
- If Bluetooth does not connect, confirm Bluetooth access is allowed, power-cycle the sensor and select Try Again.
- Diagnostics shows live readings, stability, connection state and update rate.

For additional help or to report a problem, open an issue in the VanLevel GitHub repository.
